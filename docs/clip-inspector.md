# 片段工具侧栏

## 布局与职责

- 侧栏适度加宽，向左展开；封面高度上限由 140px 提升至 200px，保持实际裁剪比例。
- 封面、选段工具、比例预设与批量工具整合为一张属性卡。内容能容纳时上下居中；内容较多或小窗口时从顶部开始滚动，不把控件居中挤出可访问区域。
- 声音控制仅放在导出弹窗。单音轨继续按默认保留声音准备；多音轨仍要求明确选择或关闭声音，预览区提供进入导出设置的入口，不静默选择第一条音轨。

## 当前片段

- 显示当前片段编号、选段时长、实际裁剪像素尺寸；每个时间轴片段编号旁也显示秒数。
- 定位入点/出点不修改选区；出点保持 strictly-before 画面边界语义。
- “设为入点/出点”使用当前播放头位置，播放时取已显示的位置，沿用已有选区校验，禁止空区间。出点不含该时刻，不改为隐式的包含末帧规则。
- 原比例、1:1、4:5、9:16、16:9 预设按显示坐标居中取最大可用范围，沿用偶数像素裁剪。原画质模式不应用手动裁剪，相关按钮禁用，但保存的手动裁剪不丢失。

## 全部片段

- 输入自定义“目标时长（秒）”，点击“应用到全部片段”或按 Enter 执行；3 秒仅为默认值，支持 5、2.5、0.125 等秒数，最多 3 位小数。编辑输入不会立即修改选段。
- 固定每段原入点，仅把出点调整为 `min(入点 + 目标时长, 源视频终点)`，短选段可延长、长选段可缩短；片尾不足目标时长时保留剩余部分，明确提示数量，不向前挪动入点。
- 使用十进制整数换算到微秒，不通过浮点乘法或静默舍入处理输入；空值、零、负数、非数字、超过小数精度或安全整数范围时禁用应用并显示提示，Enter 也不修改选段。
- “同步当前裁剪到全部”复制当前片段的裁剪和锁定方式，不修改封面、背景、封面适配或选段范围。
- 所有变化沿用 clip ID/revision 同步与主进程资源校验，不新增导出或编码路径。批量操作暂停播放，最终导出仍冻结快照、串行处理及原子无覆盖发布。
- 合计为各选段所选时长之和，重叠区间分别计入，不表示源片去重后的时长或编码后精确时长。

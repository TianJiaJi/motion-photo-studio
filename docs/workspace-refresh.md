# 编辑工作区、统一导出与临时数据

## 首次布局修订（后续交互修订见下）

1. 去掉编辑页黄色历史缓存横幅。用户明确授权丢弃应用专用 `jobs` / `media-sessions` 中的旧 `job-UUID` 内容（含缺失/损坏归属标记）；启动前重试，退出在任务、helper、资源读流完全排空后再清理。新会话始终新 UUID，不恢复过期草稿。原片、已发布 JPG、其他用户数据不在清理范围；完整预检仍拒绝 junction、软/硬链接、目录身份变化与过大遍历。发布恢复协议未放宽。
2. 文件信息、更换/关闭与导出按钮并入应用顶栏，移除第二行工具栏。输出参数离开编辑页，封面/声音侧栏收窄。保留一条时间轴和多组选区。
3. 处理/色彩/校验说明默认折叠，不把各段重复警告铺在编辑页；详情去重但保留。失败原因、未完成数量和停止原因仍明确显示。
4. 独立模态导出工作区：左侧片段列表/成品预览，右侧输出设置，底部状态与操作。支持 Escape 关闭、忙碌期间防误关、恢复编辑时暂停成品播放器。
5. 一个“导出实况”入口；当前段/全部片段共用 `exportAll` 的冻结快照、可信目录选择、校验、串行编码、无覆盖发布及取消回执。预览依然不保存；正式保存重新核验原片。主进程现在接受有序子集，仍拒绝未知/重复/删除/过期/乱序片段与变更的参数、封面。旧 `saveDraft` IPC 保留兼容与安全测试，但 UI 不再走第二套保存流程。
6. 重设计弹窗层级、留白、分段按钮、编号列表、简短结果；弹窗内部滚动，底部动作可见。小窗口适配到 860×640，不增加第二条时间轴。

## 后续交互修订：空格与逐段即时预览

- 编辑与导出共用一个原生控制器、helper 和实际 Canvas，不再在导出窗口预编码 MP4 后启动浏览器视频播放器。导出选段只调用按时间定位/播放，编码仅在正式导出时发生。
- 导出列表可逐段选择，包含每段独立裁剪/封面（原画质仍忽略但保留裁剪）；自动封面为该段起点实际预览帧的只读缩略图，正式封面仍由原片整数 PTS 路径制作，不把预览 PNG 当成最终成品。
- 选段时暂停并定位起点；区间末尾停止，再播放从该段开头开始。滑块限制在选段内；旧 epoch 晚帧丢弃，邻近尾部定位不显示下一段画面。“当前片段”指当前选中的导出预览段，不偷偷使用背景编辑页的片段；关闭弹窗恢复编辑片段与原来的播放位置及 before/after 边界语义，不改动选区。
- 空格播放/暂停，忽略按住重复触发；输入框、复选框、下拉框、滑块、文本编辑及其他模态窗口不抢键。编辑命令按钮点击后空格仍控制播放，Enter 激活按钮。导出忙碌时禁用预览交互，以免与串行编码抢占读者。
- 删除旧“查看校验与处理详情”和各段成功警告长文；错误、失败数量、停止原因与 HDR/降混同意仍保留，后台源 PTS/色彩/音轨/成品回读校验不变。

- 新增 `export-live.spec.ts` 验证四段逐一预览、空格按住去重/暂停/末尾重播、输入不抢键、裁剪/独立封面、滑块尾部不越界、切换丢弃晚帧、关闭恢复原编辑区间与排他出点、唯一 Canvas、零新媒体进程及 SVG 几何居中。封面在播放过程中保持首帧，不随播放漂移。

## 范围

本轮没有改原生解码器、输出色彩/音频校验阈值或 Motion Photo 格式。此前缺少的真实压力输入、完整冷/热性能矩阵、物理音画及手机验收仍未补齐。旧内部包不包含本轮 UI，当前运行版本以本次重新构建的 `app/out` 为准。

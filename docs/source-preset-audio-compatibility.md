# 原画质预设：导出声音兼容修复

## 用户反馈与边界

用户确认：勾选“原画质（跟随原片）”时，软件内的导出预览有声音，最终保存的文件无声；不勾选时正常。截图显示旧输出为 `pcm_s16le / 44100 Hz / 2 声道`。这与目标播放器不支持 MP4 PCM 音轨相符，但尚未取得故障最终文件和播放器型号，不能断言音轨在最终文件中被删除或已确定具体设备行为。

发布代码原已比较草稿视频与最终 JPEG 内嵌视频的 SHA256；本次不修改封装/发布路径。旧的“PCM 样本无损”验证只能证明数据保留，不能证明目标相册能播放。

## 修复

- `encode-export.ts`：源参数预设也走 AAC-LC 音频编码，仍明确选择音轨、保留源采样率/声道数。不静默丢轨或降混，不改变视频原画质参数与精确剪点。
- `Editor.tsx` / README：明确展示 AAC-LC 兼容编码与非无损音频，不再承诺此预设输出 PCM 原样样本。
- `pcm-audio.ts` 独立工具保持不变，其精确样本字节断言继续测试；不再用于此用户预设。
- 既有采样率/声道、音频起终点、完整解码、取消清理和源文件不变检查保留。

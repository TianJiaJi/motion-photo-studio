# M5 用户反馈：导出分析后无可见结果（可重现分支已修正）

## 用户现象与证据边界

用户运行已测试的旧候选，点击“导出实况”后左上角分析提示短暂出现随后消失，没有输出预览或保存位置对话框。运行日志只见 Windows 网络通知器 10108，未记录导出异常；不能据此认定用户源文件的具体编码/音轨问题。

已确认可重现的代码路径：renderer `previewOutput()` 收到 `supported=false` 后直接返回 null，原因只展示在可能滚动不可见的侧栏。原有多轨测试甚至要求缺少明确选轨时不出现预览窗口，未覆盖“明显持续反馈”的可用性要求。它不是导出成功，也不能据此说成品保存到了固定目录。

## 本次实现

- 点击预览/导出即打开同一输出对话框，进度持续可见，不再等到草稿成功才出现。
- 不支持分析结果将明确 reasons 转为持久错误；不静默关闭，不自动转码/丢轨/降混。
- 没有草稿时仍能显示错误/取消结果，“保存实况照片”保持禁用；清楚说明尚未收到保存成功确认、预览不自动保存，成功生成后需选原生保存位置。
- 关闭/ESC/取消与草稿生命周期分开，设置变化撤销旧草稿；保留已提交收据语义与原有失败保护。
- 新增真实 AVC yuv444p 原画拒绝、显式切普通后真正保存、5.1 未授权降混拒绝用例；更新多音轨和可选压力取消测试，不弱化媒体校验。

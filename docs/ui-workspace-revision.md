# 编辑器 UI 调整（用户预览反馈）

## 已确认的方向

用户要求关闭预览后继续开发，先处理以下反馈：不喜欢原有配色；缩略图时间轴需要左右两个可拖动的选段滑块；移除主界面自检/引擎/里程碑等非核心内容；采用剪映/PR 类简洁的专业桌面工作区风格，不复制其品牌素材。

## 本轮实现

- 中性深灰工作区、紧凑面板、少量低饱和薄荷色强调。紧凑顶部栏，中央预览、右侧封面/输出参数、底部横向时间轴。
- 主编辑区不再展示设备卡片、开发里程碑、引擎版本或自检卡片。手动排查入口收进原生模态“帮助与检查”；错误、引擎不可用、启动清理警告仍明确显示，不为简洁而吞掉失败。
- `Timeline.tsx` 提供左右入出点手柄、选中区间边框、非选中区域遮罩和独立白色播放头；全选片段会恢复完整范围/缩放视口。
- 手柄使用 pointer capture，支持鼠标/指针拖动，移出控件仍能完成操作；键盘方向键 1 ms、Shift+方向键 10 ms、Home/End 端点。最小区间为交互精度，不宣称每毫秒存在独立视频帧。
- `shared/timeline.ts` 使用安全整数微秒计算缩放视口坐标、边界限制，手柄不可交叉。缩放后的选段仍使用原时间轴绝对位置。
- 拖动选段不启动每像素原生解码；播放头松开再触发已有精确抽帧。预览尺寸随可用区域计算，避免竖屏素材将时间轴挤到窗口外；右侧参数独立滚动。
- 本轮 UI 初次验收时保留导入、关闭、裁剪、精确时间输入/逐帧、封面与参数，原画/导出尚未接通。随后 M3 已新增真实原画开关与私有“预览输出”，并在 `bc619ce4e` 通过实际桌面验证；最终“导出实况”仍禁用。UI 改版或私有草稿均不等于最终 Motion Photo 发布验收。

# 导入首页改版

## 界面范围

仅重设计导入首页，不改变时间轴、编辑器或导出弹窗。

- 左侧标题、简短说明与唯一“选择本地视频”入口；右侧为项目内原创 SVG 实况照片插画，不是第二个播放器，也不加载远程图片。
- 下方三步制作流程替代空白的装饰时间轴；保留本地处理、不上传、不改原片的说明。
- 移除“取消导入”按钮及原生索引/兼容准备长文。系统文件选择框仍使用自身的取消按钮。
- 实际导入失败明确显示，入口恢复可用；引擎启动和校验错误继续使用已有的状态与错误区。
- 小窗口适配、键盘焦点、屏幕阅读器状态、减少动态效果设置均保留。

## 状态与安全

`Editor.openVideo()` 先进入选择状态，不把打开系统文件框误报为正在读取。主进程确认原生选择框返回文件后，通过 `motion:media:import-selected` 通知发起请求的渲染进程，再执行原来的 `MediaSession.open()`；事件不携带路径，不新增渲染进程传路径的能力。

读取状态显示简短的真实等待提示，不伪造百分比。取消选择回到待选状态，出错可以重试；请求结束时解除本次状态订阅。真实预览准备仍在导入后的编辑器中显示，不隐瞒兼容处理。

原有 `cancelImport` IPC 保留，取消/退出的资源释放机制不变；本轮仅移除多余的界面入口。

## 自动化与限制

主分支/PR 自动构建固定 Rust 原生引擎、执行检查并编译应用；工件名使用 run ID / SHA，避免 PR ref 含斜线导致上传失败。版本/手动完整打包仍需 `ENGINE_BUNDLE_URL` 和 `ENGINE_BUNDLE_SHA256`，目前未配置；本轮不绕过此供应/许可前置。

原计划第10步不因本轮功能测试或提交成功自动完成：真实素材性能、严格音画门槛、真实HDR/硬解身份、干净离线环境及更广泛设备验收仍需区分记录。当前包未签名，仍为内部开发/手动验证用途。

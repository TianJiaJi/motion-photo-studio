# 快速导入与多片段实况导出

对应计划：`plans/instant-import-multi-clips.md`。本文件记录实现方式、性能基线与已知回退。

## 审查状态

六步实现与本轮回归执行已完成；这不等于所有性能/设备验收目标达标，未满足及未验证项见文末。初次继承的实现曾是未验证草稿，独立复核发现：协议声明 v2 但 wire v1、快路径预检全部音轨、未接通的多片段 IPC 导致类型检查失败，以及一次完整集成命令因 Windows 路径语法错误未执行。不能沿用此前“完整测试已运行”的理解。

上述缺陷已修复并增加测试。旧证据仅代表其实际测量范围，不构成端到端、物理音画同步或真实素材验收。用户后续明确纠正多行设计：当前实现始终只显示一条时间轴，同轨叠加多组范围选择器。

## 快速导入（按需媒体读取）

实现：`app/src/main/media/{quick-import,local-frame-resolver,frame-provider}.ts`，协议 v2（`locate` 增加严格 `boundary` 语义），引擎 0.2.0。

- **就绪门槛（有界）**：复用 `open` 的 probe（不再二次探测）；原生 `open` 后用 64 帧窗口对照源 PTS 与原生时间戳（与严格 `mapNative` 同一整数有理区间规则），建立时间原点；仅对所选音轨用源端/原生端各最多 48 块实际样本解码校准 `offsetHns`；通过唯一的采样率/声道元数据对应选择原生轨道，身份不唯一则明确回退。首帧还须成功读回像素。窗口内不连续/不匹配即回退严格整片准备并显示原因。
- **扫描监测**：`tests/integration/fast-import.test.ts` 记录子进程参数与原生请求；启动测试还限制 FFmpeg 帧窗口、原生视频 64 帧与所选音频 48 块。此前约 0.7s 的记录来自 **6s / 640×360** 合成片的准备函数，不是 1080p、桌面端到端或冷启动验收。监测器本身不能证明任意局部解码都具有硬预算，仍需逐项审查。
- **播放/拖动**：复用 Rust `locate/read`、帧缓存与 WASAPI 时钟；入点 at-or-after、出点 strictly-before（协议 v2 `boundary`）；定位起点失败时按 0/1s/5s/30s 逐级回搜，不拿最后一帧冒充边界命中。
- **身份契约**：显示帧可携带 `pts/sourceFrame = null`（不伪造）；逐帧与封面捕获时用 `LocalFrameResolver`（复用导出 `frameAtOrAfter` 的源 PTS 邻域核验）解析精确源帧，显示时间与源帧时间相差 > 8µs 或不唯一即明确报错，不保存相邻帧。
- **声音**：offset 严格路径同公式（实测首样本对齐，含 AAC priming/延迟轨）；与画面窗口原点相差 >100ms 回退，>2ms 警告。
- **已知限制**：HDR/旋转/非方形像素/多视频流仍需兼容准备。启动时序窗口的比较阈值是 **2 个 100ns 单位**，不是 2 个源 tick，且不能据首窗口声称全片映射已验证。局部解析每次查询最多 4096 帧、向前回搜最多 32 秒、15 秒期限；缓存命中前仍检查源文件。源 PTS 与原生样本时间还需整数有理校验，允许差为 2 个 100ns 单位；8µs 显示时间邻近判断不能替代该校验。旧 epoch 的捕获会被拒绝；局部取消不会杀死共享 helper。

## 多片段与批量导出

- 一条共享刻度/缩略图/播放头的时间轴，同一轨道内包含多个范围选择器；新增不会复制时间轴。20 组重叠选择器的轨道高度不变，编号按钮提供被遮挡范围的激活与删除。
- 主进程按 clip ID/revision 管理封面、分析与草稿；删除身份不可复用，旧响应被拒绝。切换片段恢复独立封面/裁剪；共享设置变化使所有相关修订失效。重型输出草稿最多保留一份。
- 批次在可信目录对话框打开前冻结：主进程拒绝编辑和换素材，停止预览并排空旧任务，快照不包含渲染端任意路径。批次采用原有 analyze → render → validated publish 流程，原画质仍是 source-following 高保真转码，不偷偷改为包复制。
- 编码临时文件放在受管会话目录，发布暂存采用既有 Publications 所有权日志。每段完成/失败后清理；清理失败停止批次并保留成功回执。
- 文件名使用稳定创建编号，普通冲突和原子发布时的竞态均重试后缀，最终 link 不覆盖。批次上限 100 段，命名最多 1000 次尝试。
- 普通单段内容错误继续，源变化/磁盘/目录/清理错误停止；结果包括成功、失败、取消和未执行。原子提交后的文件永不报为未发布取消，迟到取消可取回回执。编码/封面警告保留到最终结果。

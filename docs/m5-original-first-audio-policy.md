# M5 原片参数一键预设：历史需求与验证记录

> **0.1.3 更新：** 下文 PCM 保持/禁止默认转 AAC 的内容属于旧版本策略，不再是当前预设。用户反馈旧文件无声后，已改为保持采样率/声道的 AAC-LC 兼容编码，并经用户确认恢复声音；见[修复记录](source-preset-audio-compatibility.md)。以下历史事实保留，不改写旧包的验证结果。

**用户最终澄清优先于以下历史讨论：** 点击原“无损”开关，是让软件自动跟随原片参数、省去手动设置；允许编码，不要求把实现限定为严格码流复制。界面改称“原画质（跟随原片）”，明确高保真编码非数学无损。主界面不再用 H.264-only/AAC-only 的直接复制准入挡住正常转码。视频保持原显示尺寸和帧时序，音频跟随原采样率与声道；PCM16用相同PCM保留声音样本。关闭后恢复手动设置。

## 用户确认的最新标准

1. 视频目标是画质，不强制实现一定不经过编码。用户选择“原画优先＋高保真兼容”：能复制则复制；必要高质量转码须明确标“高保真，非严格无损”，不擅自降分辨率/帧率。
2. 用户随后明确音频也不要压缩。此要求不因第1项而被推定授权有损音频转换。默认保留原音轨、采样率、位深、声道；不默认 AAC、重采样、降混或丢声音。若原始组合相册不支持，应如实说明冲突再确认，不能为导出成功偷偷降质。
3. “HEVC 复制＋PCM 转 AAC”提案已撤回：AAC 是有损，不符合用户音频要求。相关工作分支未发布为候选；自动选择 AAC 的策略已禁止，新增单元保护。

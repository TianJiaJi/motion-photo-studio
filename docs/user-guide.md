# 实况工坊：一期操作说明（0.1.1 预设修正验证中，M5 未验收）

适用于当前 Windows x64 内部功能版；系统版本范围、新安装包及最终手机结果仍在验收。M1 回滚包只有早期基础功能，不能按本手册当作新版。运行时无需 Node、系统 FFmpeg 或上传服务器。

## 从视频到单个实况 JPG

1. **导入视频**：用原生文件选择器选择原始视频。已有实况 JPG 再编辑不属于一期。源文件始终只读；素材路径变化或内容修改后需重新导入。
2. **预览和选段**：白色播放头与左右裁切手柄独立；拖左右手柄选择保留区间，可缩放/平移时间轴。手柄方向键按 1 ms、Shift+方向键按 10 ms 移动；这是交互精度，实际视频剪点仍受帧/GOP 边界限制，不代表每毫秒都有一张独立画面。
3. **画面与参数**：普通模式可裁切画面、设置帧率、分辨率与 CRF。默认 30 fps、1080 最长边且不放大、CRF 23；以显示的最终宽×高为准。CRF 越小通常文件越大；CRF 0 也仍是转码，不是原画直出。
4. **声音**：原片一条音轨可默认保留；有多条时必须明确选择，或明确取消保留，不能静默丢弃。手动模式如需多声道转立体声需同意，跟随原片预设不自动降声道。原片无声不会凭空添加声音；音乐/音轨编辑是二期。
5. **封面**：选择“使用当前帧”，或上传静态 JPG/PNG。它们从原始素材重新处理，不把低清代理截图当最终封面。比例不同时明确选择裁满/留边和背景；透明区会合成背景，不拉伸。封面经过方向、实际 ICC→sRGB 和 JPEG 编码，不属于音视频不重编码承诺。
6. **导出实况 / 预览输出**：立即打开输出窗口显示分析/处理进度；失败原因持续显示，不会闪一下就消失，也不是存到了其他目录。0.1.1“跟随原片”允许自动高保真编码，不再因不满足直接复制条件而要求你手调。生成实际私有视频/封面后检查请求与实际区间、尺寸/帧率、声音和说明；默认未另选封面时使用实际输出起点帧。
7. **保存实况照片**：在原生保存对话框选择新的 JPG/JPEG 名称。只有显示“已保存 文件名”才算完成。最终是**一个 JPG 文件**（内含视频），不需要另外传 MP4。仅生成预览、进度写入到 100% 或关闭对话框都不等于最终保存。

## 原画质（跟随原片）：一键预设

这是用户最终确认的交互，不再将“必须码流复制”当作开关前提，也不让你为普通 HEVC/PCM 素材手调参数。

- 开启后采用完整有效画面，原显示尺寸、原帧时序/FPS、原音频采样率与声道参数；暂停手动分辨率/FPS/CRF等设置，关闭后恢复。比如原片1080p60，应输出1080p60，不套用默认1080最长边或30fps。
- 软件可以重新编码，自动采用高保真兼容视频编码（当前CRF16）；**不是数学严格无损**，不声称与源编码器CRF/码率完全一致。剪点仍对齐实际帧，检查请求/实际范围。
- 从0.1.3开始，音频统一使用 AAC-LC 兼容编码（包括 PCM 输入），保留源采样率与声道数，不静默降混；这解决了已反馈的“预览有声、最终文件无声”场景，但不承诺所有相册支持。
- 音频会重新编码，非样本无损；预览显示实际采样率/声道及处理说明。多轨仍必须明确选轨或明确不保留，不自动选择。旧版本导出的 PCM 文件需重新导出，不会自动修复。
- HDR→SDR仍需要同意；JPEG封面仍是单独编码。底层严格码流复制模块/历史CLI回归不是此按钮的定义。

## HDR、独立封面与方向

HDR 需明确同意将预览、封面和输出转为 SDR；不会保留原 HDR 效果，也不改写源文件。视觉保真仍需最终设备检查。

上传封面，或没有在最终视频中实际保留对应帧的封面，会标为“无对应视频帧”；不会悄悄换成第 0 帧。方向/像素比例会按当前路径归一或保留，并在实际输出预览中呈现；保存前应检查竖屏/裁切是否符合意图。

## 取消、失败与磁盘

- 保存对话框取消不会创建成品。原子提交前取消无最终文件；提交后才收到取消，则仍如实报告已保存，不能当作撤回。
- 同名目标从不覆盖，请另选文件名；也不能覆盖源文件或将成品保存到应用缓存/恢复工作区。
- 文件系统需支持本版本安全发布所用的同卷硬链接。不支持时选其他本地位置；不要期待直接保存到 MTP 手机虚拟目录，先保存电脑再原文件传输。
- 需同时考虑应用私有缓存和目标目录空间；无产品时长/大小上限不代表磁盘、内存、编码器或手机无限。大文件可能多次读取校验，写入完成后仍需等待“已保存”。
- 原片修改/删除、目标目录无权限/被占用、空间不足或校验失败会报错，不冒称完成。必要错误不会隐藏；引擎信息和自检位于“帮助与检查”。
- 临时工作区锁定时保留恢复记录并警告，下次启动只清理可确认所有权的缓存；不会删除已保存成品或用户原片。若不确定目录归属会保留而非强删。

## 传入小米相册检查

当前只有 Redmi K70E / OS `3.0.304.0.WNLCNXM.C11` / Android 16 / Gallery `4.3.1.18` 的 M0 对照结果；完整新版链路仍需 M5 复测，不能宣称全部小米/旧系统支持。

1. 使用 USB 原文件复制最终 JPG，不经聊天软件压缩/转码；使用唯一文件名避免旧相册缓存。
2. 核对照片封面、实况标志、长按完整播放、方向/裁切、声音与音画起止。
3. 退出相册再打开，确认仍识别并能播放。长片逐项记录实际能否完整播放，不能从 3 秒通过推断 1 分钟/10 分钟或更长都支持。
4. 如手机系统/相册升级，请记录新版本重新验证。电脑播放器正常或 XMP 字段完整不是手机验收。

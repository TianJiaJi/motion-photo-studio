# Motion Photo Studio v0.1.5

## 下载与运行

Windows x64 免安装预览版。下载本页的 `MotionPhotoStudio-0.1.5-win-x64-portable.zip`，**完整解压**到可写目录，再运行 `Motion Photo Studio.exe`。不要仅复制 EXE，也不要直接在压缩软件里运行。使用 `SHA256SUMS.txt` 校验附件。

本版未签名，不是安装器；Windows N 等缺少 Media Foundation 的系统仍需补齐系统组件。应用运行时离线，不下载编码器。

## 本次更新

### 快速导入与单时间轴多片段
- 导入优先准备可用画面和已确认声音，不强制先扫描完整视频；不支持的原生解码会明确转入兼容准备，不静默变成无声预览。
- 一条时间轴管理多个独立选段，支持重叠片段、各自的裁剪及封面；新片段默认从播放头创建，初始片段覆盖整段素材。
- 统一导出窗口选择目录一次，按冻结的片段快照串行生成独立 Motion Photo JPEG；取消后保留已经发布的文件，不覆盖同名成品。

### 更实用的片段侧栏
- 放大封面、加宽并整合片段工具；显示每段时长、当前尺寸、总段数和合计时长。
- 新增入出点定位、以播放头设界、原比例/1:1/4:5/9:16/16:9 裁剪及同步裁剪。
- **批量时长可自定义**，支持 5 秒、2.5 秒等整数/小数，最多三位小数。3 秒只是默认值，不是限制。
- 批量调整固定每段入点，仅改变出点；片尾不足目标时长时保留剩余部分，不向前移动入点；独立封面不被覆盖。
- 声音设置集中到导出窗口，多音轨素材仍需明确选择或省略。

### 即时预览与交互修复
- 导出窗口复用同一个原生 Canvas 即时逐段预览，无需预先编码；关闭后恢复编辑片段及游标边界语义。
- 修复点击/拖动时间轴入点、出点或播放头后空格无法播放；保留长按去重、方向键编辑和表单原生键盘行为。
- 播放头焦点使用本体高亮，移除容易误认成选区的小方框。
- 重新设计导入首页，区分系统选文件与读取素材状态；改善小窗口布局、音轨入口遮挡及侧栏滚动。
- 清理仅限应用私有临时目录的历史缓存，不删除原视频、输出或任意用户文件。

## 构建、源码与许可

本页发行附件由对应提交的云端流水线产生；不把仅含 JavaScript 的源码编译工件当作完整应用。媒体引擎改为从固定源码提交构建，不直接重新发布开发机上的内部 FFmpeg 快照。

同页的 `MotionPhotoStudio-0.1.5-third-party-sources.tar.gz` 提供对应第三方源码、补丁、构建资料及版本记录；`ENGINE-BUILD-MANIFEST.json` 和 `SHA256SUMS.txt` 记录来源与摘要。运行包内保留第三方许可和替换说明。源码附件不必解压到应用目录。

## 已知限制

- 这是预发布，不代表所有手机相册、干净离线机器或物理音画同步都已验收。
- 部分 PCM 素材仍需较慢的兼容准备，4K 精确步进/封面也可能较慢；不承诺全部素材 1–3 秒导入或冷启动 P95 达标。
- 不包含项目保存或撤销系统；关闭素材/应用前，请先导出需要保留的编辑。
- 大文件/两小时压力素材在本地缺失，该项仍跳过，不计为通过。旧内部包的验收记录不替代本次发行包结果。
